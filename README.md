# AiFotofilm Pro Web V20.5.1
Gemini Canvas uygulamasının ayrı Vite/React web sürümü.

## Güvenlik
- Google OAuth **Client Secret** dosyasını veya Gemini API anahtarını GitHub'a yüklemeyin.
- Kullanıcılar kendi Gemini API anahtarlarını Ayarlar'dan girmelidir.
- Drive bağlantısı kullanıcıya özeldir; bağlantı belirteci yalnızca tarayıcı belleğinde tutulur.
- OAuth için GitHub Pages HTTPS origin adresini Google Cloud Authorized JavaScript origins'e ekleyin.

## Yayınlama
Bu dosyaları `aifotofilm-web-staging` dalının köküne yükleyin. GitHub Settings > Pages > Source: GitHub Actions.
